<product_requirements>
The user requested an enterprise-grade AI CFO agent named MyGlobalCFO, designed to automate finance operations across multi-entity organizations.

**Core Capabilities:**
*   **Email Integration:** Connect securely to Gmail/Outlook APIs, categorize financial emails, parse attachments (PDF, CSV, XLS, DOCX), extract data (invoices, statements, receipts), auto-populate accounting systems, and send templated replies.
*   **Accounting Software Integration:** Integrate with Xero, Sage, QuickBooks, or Zoho Books via OAuth, post transactions, auto-tag to cost centers, and generate financial reports (management accounts, cash flow). Prioritized Xero first.
*   **Bank Connectivity:** Connect to bank feeds (Plaid, TrueLayer, Open Banking APIs) for daily reconciliation, anomaly detection. Prioritized TrueLayer first.
*   **Multi-Entity Consolidation:** Support multiple legal entities, auto-convert currencies, apply local tax rules, consolidate group-level financials (P&L, balance sheet, cash flow) in real-time.
*   **Dashboard and Reporting:** Real-time insights (revenue, costs, profit, cash flow), 30/60/90-day runway forecasts, KPI visualization (EBITDA, AR/AP ageing), export/embed to Google Looker Studio/Notion. User selected an Executive Dashboard design.
*   **Finance Sourcing:** Search for finance products (loans, credit lines, grants), compare rates, summarize recommendations.
*   **LLM for Data Extraction:** Use OpenAI GPT-5 for parsing attachments.

**Workflow:** Email → Attachment → Data Extraction (GPT-5) → Accounting Software Entry (Xero) → Bank Reconciliation (TrueLayer) → Dashboard Update → Finance Deal Suggestions.

**Additional Requirements:**
*   Multi-tenant deployment (white-label dashboard with real-time charts and entity switcher).
*   Payment gateway for subscription billing.
*   Ability to add/remove entities.
*   Filtering and sorting for recent transactions.
*   TopCo/Subsidiary hierarchy for corporate structures.
*   View Details on KPIs to show charts/spreadsheets.
</product_requirements>
